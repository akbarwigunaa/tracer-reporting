1. Ringkasan

ChartConfigService menghasilkan konfigurasi Chart.js yang disimpan sebagai JSON di kolom chart_config tabel analysis_results, lalu di-render client-side. Mendukung 3 tipe chart: pie, bar, dan grouped_bar. Return null untuk parameter tanpa chart.
