1. Ringkasan

Implementasi dua view utama untuk modul analisis: halaman daftar (analysis/index) dan halaman detail (analysis/show). Halaman detail menampilkan 13 parameter analisis dengan narasi otomatis, tabel statistik per tipe, dan chart Chart.js untuk 8 parameter yang memiliki visualisasi.

2. File yang Dimodifikasi

resources/views/analysis/index.blade.php — Daftar tracer study dengan tabel + tombol Lihat
resources/views/analysis/show.blade.php — Detail 13 parameter + Chart.js (291 lines total)

3. Analysis Index

Tabel daftar semua tracer study dengan kolom: Institusi/Prodi, Jenjang, Tahun Lulusan/Tracer, Response Rate, Status (badge), dan Aksi (tombol "Lihat" hanya untuk status completed). Empty state dengan CTA upload.

4. Analysis Detail — Struktur

4.1 Header Card

Info tracer study: nama prodi + institusi, badges (jenjang, tahun lulusan, tahun tracer), dan 3 KPI besar (Responden, Total Lulusan, Response Rate).

4.2 Quick Navigation

Badge navigation bar — 13 anchor links (#param-{key}) untuk scroll ke parameter tertentu.

4.3 Parameter Cards (×13)

Setiap parameter ditampilkan dalam card terpisah dengan:

  • Header: nomor urut (badge) + nama parameter + tipe statistik
  • Narasi: teks otomatis dari NarrativeService dalam box bg-body-secondary
  • Tabel statistik: layout berbeda per tipe (lihat section 5)
  • Chart: Chart.js canvas di kolom kanan (col-lg-7) jika chart_config ada
