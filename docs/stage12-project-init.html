Keputusan Implementasi

#KeputusanAlasan
1 Laravel 13 (bukan 12) Versi terbaru saat instalasi, backward-compatible, semua fitur yang direncanakan di arsitektur tetap berlaku
2 PHP 8.5 (bukan 8.4) Homebrew menyediakan PHP terbaru. Semua fitur PHP 8.4 tersedia, plus improvement tambahan
3 Session & cache: file driver Tidak perlu database driver — single user, tidak butuh shared state, menghindari tabel tambahan
4 Queue: sync File Excel ≤5000 baris diproses <30 detik — tidak perlu async queue
5 Hapus default migrations, User model Proyek tanpa authentication — tabel users, cache, jobs tidak dibutuhkan
6 AdminLTE via npm + Vite Modern build pipeline, tree-shaking, HMR saat development
7 Chart.js exposed as window.Chart Chart config datang dari Blade (JSON), dirender di inline <script> per parameter card
