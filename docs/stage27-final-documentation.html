Project Overview

Web Tracer Reporting System adalah aplikasi berbasis web yang mengolah data Tracer Study dari file Excel (format DIKTI) menjadi dashboard analitik interaktif dan laporan Word (.docx) otomatis. Sistem membaca data Excel apa adanya tanpa cleaning, menghitung statistik untuk 13 parameter analisis, menghasilkan narasi otomatis, dan memvisualisasikan hasil dalam grafik Chart.js.

Keputusan Desain Utama

  • No authentication — single personal user, app opens directly to dashboard
  • Export hanya ke Word (.docx via PHPWord) — no PDF export
  • No data cleaning — sistem membaca Excel as-is dari format template DIKTI
  • No external API — fully self-contained
  • Each upload standalone — no multi-period comparison
  • Meta info manual — nama PT, prodi, total lulusan diinput saat upload; response rate auto-calculated

Fitur Utama

Upload Excel
Upload file Excel format DIKTI dengan meta info (institusi, prodi, jenjang, tahun). Drag & drop dengan validasi format dan duplikasi.
Dashboard
4 KPI cards (Total Tracer Study, Analisis Selesai, Total Responden, Total Laporan) + tabel data dengan aksi cepat.
Analisis Otomatis
13 parameter analisis dengan statistik (6 tipe), narasi template, dan grafik Chart.js (pie, bar, grouped bar).
Report Generation
Laporan Word (.docx) otomatis: cover, summary, 13 parameter sections dengan narasi & tabel statistik.
Cross-linked Navigation
Semua halaman terhubung: Dashboard ↔ Analysis ↔ Reports. Generate & download laporan dari mana saja.
Config-Driven Processing
Parameter, categories, chart types, dan narrative templates semuanya dikonfigurasi via config files, bukan hardcoded.

Arsitektur

Aplikasi menggunakan Clean Architecture dengan 4 layer yang memisahkan concerns secara ketat. Business logic berada di Service Layer, bukan di Controller.

Design Patterns

  • Repository Pattern — 3 interfaces + 3 Eloquent implementations, bound via ServiceProvider
  • Service Layer — 6 services + interfaces, all injected via constructor DI
  • Config-Driven Processing — config/tracer.php (13 parameters) + config/narratives.php (templates)
  • SOLID Principles — Single responsibility per service, interface segregation, dependency inversion

Service Layer

Semua business logic diimplementasi di 6 services yang terikat via interface di RepositoryServiceProvider (9 total bindings: 3 repos + 6 services).

ServiceResponsibilityInputOutput
ExcelReaderService Baca data Excel per parameter File path, config array raw data per kolom
StatisticsService Hitung statistik (6 tipe) Parameter key, config, raw data array stats (frequencies, mean, dll.)
NarrativeService Generate narasi dari template Parameter key, stats, meta string narrative text
ChartConfigService Buat config Chart.js Parameter key, config, stats array chart config (or null)
TracerAnalysisService Orchestrate analysis pipeline TracerStudy model 13 AnalysisResult records
ReportGeneratorService Generate Word .docx report TracerStudy model Report model + .docx file

Processing Pipeline

Upload Excel
  → ExcelReaderService.read()        // extract raw data per parameter
  → StatisticsService.calculate()     // compute stats (6 types)
  → NarrativeService.generate()       // fill template narratives
  → ChartConfigService.generate()     // build Chart.js configs
  → Save 13 AnalysisResult records    // DB persistence
  → ReportGeneratorService.generate() // on-demand Word export

Setup & Running

Prerequisites

  • PHP 8.5+ with extensions: mbstring, xml, zip, gd
  • Composer 2.x
  • Node.js 20+ & npm
  • MySQL 8+

Installation

composer install
npm install
cp .env.example .env
php artisan key:generate
php artisan migrate

Development

php artisan serve        # Start dev server (port 8000)
npx vite                 # Start Vite dev server
php artisan test         # Run test suite

Usage

  1. Buka http://localhost:8000 — langsung masuk Dashboard
  2. Klik Upload Data — isi meta info + upload Excel format DIKTI
  3. Sistem otomatis menganalisis 13 parameter & membuat grafik
  4. Klik Lihat Analisis untuk melihat statistik, narasi, dan chart
  5. Klik Generate Laporan untuk membuat file Word (.docx)
  6. Download laporan dari halaman Laporan
