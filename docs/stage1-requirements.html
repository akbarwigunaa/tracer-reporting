Web Tracer Reporting System

Analisis Kebutuhan Sistem

Dokumen analisis kebutuhan fungsional dan non-fungsional berdasarkan template Excel Tracer Study DIKTI, dengan 13 parameter analisis, engine pengolahan otomatis, dan export laporan ke Word.

1.1

Deskripsi Umum Sistem

Aplikasi berbasis web yang menerima file Excel berisi data Tracer Study sesuai template DIKTI, kemudian mengolahnya secara otomatis menjadi dashboard analitik bergaya Business Intelligence, statistik, grafik, tabel, narasi interpretasi, serta laporan formal yang dapat diekspor ke Microsoft Word.

Sistem ini bukan sistem tracer online. Tidak menyediakan pengisian kuesioner, registrasi alumni, data cleaning, validasi data, maupun integrasi API eksternal. Tidak ada autentikasi — aplikasi langsung terbuka ke dashboard. Setiap upload menghasilkan satu set analisis independen.

Template terdiri dari 3 sheet. Sheet "data tracer" menjadi sumber data utama (86 kolom, header di baris 3, data mulai baris 4). Sheet "PARAMETER LAPORAN" mendefinisikan parameter analisis. Sheet "pengolahan" berisi referensi logic.

1.9

Batasan Sistem

× Hanya menerima file Excel (.xlsx) sesuai template yang ditentukan
× Tidak ada proses data cleaning — sistem mengasumsikan data sudah bersih
× Tidak ada validasi logika data — sistem membaca dan mengolah apa adanya
× Tidak ada integrasi API eksternal, webhook, maupun koneksi ke sistem lain
× Tidak ada autentikasi — aplikasi langsung terbuka tanpa login
× Export hanya ke Microsoft Word (.docx) — tidak ada export PDF
× Setiap upload berdiri sendiri — tidak ada perbandingan antar tahun
× Read-only terhadap data sumber — sistem tidak memodifikasi file Excel
1.10

Asumsi

  1. Template Excel sudah ditentukan dan memiliki sheet bernama "data tracer" dengan header di baris 3
  2. Data dimulai dari baris 4 sheet "data tracer" dengan 86 kolom sesuai mapping
  3. Kolom menggunakan kode field DIKTI (f-codes) yang sudah terdefinisi
  4. Administrator memasukkan meta informasi (nama PT, nama prodi, total lulusan) secara manual saat upload
  5. Response rate dihitung otomatis: total responden dalam data / total lulusan yang diinput
  6. Satu sesi upload menghasilkan satu set analisis dan satu laporan
  7. Sistem dijalankan di environment lokal atau server perguruan tinggi
1.11

Keputusan yang Telah Disetujui

Apakah sistem memerlukan autentikasi login?
Tidak — pengguna tunggal, aplikasi langsung terbuka ke dashboard tanpa login. Tidak ada tabel users.
Format export laporan apa saja yang didukung?
Hanya Microsoft Word — menggunakan PHPWord. DomPDF tidak digunakan.
Apakah Penilaian Kemampuan Diri masuk sebagai parameter analisis?
Ya — menjadi parameter ke-13 dengan tabel perbandingan indeks A vs B dan grouped bar chart per kompetensi
Apakah sistem mendukung perbandingan antar tahun?
Tidak — setiap upload berdiri sendiri sebagai satu set analisis independen
Bagaimana meta informasi (total lulusan, response rate) diperoleh?
Input manual — Administrator mengisi nama PT, nama prodi, total lulusan universitas & prodi via form saat upload. Response rate dihitung otomatis.
