1. Ringkasan

ExcelReaderService membaca file Excel tracer study (.xlsx) menggunakan PhpSpreadsheet, melakukan mapping f-code dari header row ke kolom secara dinamis, dan mengekstrak data mentah untuk semua 13 parameter analisis. Service mengikuti Interface + Implementation pattern dan teregistrasi di ServiceProvider.

3. Interface

interface ExcelReaderServiceInterface
{
    /**
     * @return array<string, array<int, mixed>>
     */
    public function read(string $filePath): array;
}

Method read() menerima path file Excel dan mengembalikan array keyed by parameter_key, masing-masing berisi array nilai mentah dari kolom terkait.

4. Arsitektur Service

4.1 Flow Proses

  1. Load spreadsheet — IOFactory::load($filePath)
  2. Get sheet — Cari sheet "data tracer" (throw RuntimeException jika tidak ditemukan)
  3. Build f-code map — Scan header row 3, bangun mapping f-code → column index
  4. Read parameters — Untuk setiap parameter di config/tracer.php:
    • Parameter 1–12: resolve kolom via f-code (fallback ke column letter), baca semua nilai non-empty
    • Parameter 13 (kemampuan_diri): untuk setiap 7 kompetensi, resolve 2 kolom (column_a, column_b) via f-code
  5. Return — Array keyed by parameter_key

4.2 Strategi Resolusi Kolom

PrioritasStrategiDetail
1F-code lookupScan header row, cocokkan f-code (case-insensitive)
2Column letter fallbackGunakan column key dari config (hanya parameter 1–12)
—RuntimeExceptionJika keduanya gagal

4.3 Private Methods

MethodFungsi
getSheet()Ambil worksheet by name, throw jika tidak ada
buildFCodeMap()Scan header row → ['f8' => 13, 'f502' => 76, ...]
resolveColumn()F-code lookup + column letter fallback
readColumn()Baca semua nilai non-empty dari satu kolom (row range)
readKemampuanDiri()Baca 7 kompetensi × 2 kolom (values_a, values_b)
resolveFCode()Lookup f-code di map, throw jika tidak ada
