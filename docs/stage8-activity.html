Activity 1: Upload & Analisis Data Tracer

Proses utama dan paling kompleks. Mencakup UC-02, UC-03, UC-04. Dua swimlane: Pengguna (interaksi UI) dan Sistem (proses backend).

Alur Langkah Detail
  1. Pengguna — Buka halaman Upload (GET /upload)
  2. Pengguna — Isi 5 field meta institusi: nama PT, nama prodi, tahun, total lulusan PT, total lulusan prodi
  3. Pengguna — Pilih file Excel (.xlsx) via drag-and-drop atau file browser
  4. Pengguna — Klik tombol "Upload & Proses" (POST /upload)
  5. Sistem — UploadTracerRequest memvalidasi: file (.xlsx, ≤10MB), field wajib terisi, tahun valid
    Gagal: Redirect kembali ke form dengan pesan error, input tetap terisi (old input)
  6. Sistem — Simpan file Excel ke storage/app/uploads/, buat record tracer_studies (status: processing)
  7. Sistem — ExcelReaderService membaca sheet "data tracer" → array responden (f-code keys)
  8. Sistem — Hitung total_responden, response_rate_pt, response_rate_prodi
  9. Sistem — Loop 13 parameter (dari config/tracer.php):
    a. StatisticsService → hitung sesuai statistic_type
    b. ChartConfigService → build JSON konfigurasi Chart.js
    c. NarrativeService → generate paragraf dari template
    d. Simpan record analysis_results
  10. Sistem — Hapus file Excel sementara dari storage
  11. Sistem — Update status → "completed", redirect ke /analysis/{id} dengan flash message
  12. Pengguna — Melihat halaman analisis dengan 13 parameter cards

Activity 2: Generate Laporan Word

Proses pembuatan file .docx dari data analisis yang sudah ada. Mencakup UC-06.

Alur Langkah Detail
  1. Pengguna — Buka halaman analisis tracer study yang sudah completed
  2. Pengguna — Klik "Generate Laporan Word" (POST /reports/{id}/generate)
  3. Sistem — Ambil data tracer_studies + 13 analysis_results dari DB
  4. Sistem — ReportGeneratorService membangun dokumen PHPWord:
    • Cover page (nama PT, prodi, tahun)
    • Daftar isi otomatis
    • Ringkasan (response rate, total responden)
    • 13 bab parameter (tabel + narasi)
  5. Sistem — Simpan .docx ke storage/app/reports/, create record reports
  6. Sistem — Redirect ke /reports dengan flash message sukses
  7. Pengguna — Melihat daftar laporan dengan entry baru, siap download
8.3

Activity 3: Hapus Data

Proses penghapusan tracer study atau individual report. Mencakup UC-08. Decision point pada konfirmasi modal.

Alur Langkah Detail
  1. Pengguna — Klik tombol "Hapus" pada item (tracer study atau laporan)
  2. Sistem — Tampilkan modal konfirmasi: "Yakin ingin menghapus [nama]?"
  3. Decision — Pengguna konfirmasi atau batal?
    Batal: Modal ditutup, tidak ada perubahan → End
  4. Pengguna — Klik "Ya, Hapus" pada modal
  5. Sistem — Hapus record dari DB. CASCADE: analysis_results + reports ikut terhapus
  6. Sistem — Model event (deleting): hapus file .docx fisik dari storage
  7. Sistem — Redirect ke halaman sebelumnya dengan flash message sukses
