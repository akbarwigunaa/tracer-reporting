6.1

Layout Global (AdminLTE 4)

Semua halaman menggunakan AdminLTE 4 layout: sidebar kiri tetap 250px, topbar dengan breadcrumb, dan area konten utama. Tanpa header user/login karena tidak ada autentikasi.

KomponenSpesifikasi
SidebarLebar 250px, collapsible ke 70px. Background gelap. 4 menu item: Dashboard, Upload Data, Analisis, Laporan.
TopbarTinggi 48px. Breadcrumb kiri. Toggle sidebar kiri.
Content AreaPadding 1.25rem. Background: body grey. Cards sebagai container utama.
TypographyFont sistem (AdminLTE default). Heading: 600/700 weight. Body: 400.
Color SchemePrimary: Bootstrap blue (#0d6efd). Success: green. Warning: amber. Danger: red. Mengikuti AdminLTE 4 palette.
ResponsiveSidebar auto-collapse di <992px. Grid cards stack di <768px.

6.7

Keputusan UX

KeputusanAlasan
Tanpa login screen Single user, langsung masuk dashboard. Mengurangi friction.
Sidebar 4 menu saja Minimal navigation. Setiap menu = satu concern yang jelas.
Parameter cards vertikal (scroll) 13 parameter di satu halaman scrollable lebih baik daripada tab/pagination — user bisa compare tanpa klik.
Generate laporan dari halaman Analisis Contextual action: user sudah melihat data, lalu decide untuk generate. Bukan dari halaman terpisah.
Drag-and-drop upload Familiar pattern. Fallback klik untuk select file tetap tersedia.
Flash message setelah proses Konfirmasi instan: "Data berhasil diproses: 89 responden dari 120 lulusan". Menggunakan Bootstrap alert.
Konfirmasi modal untuk hapus Satu-satunya destructive action di UI. Modal "Yakin hapus?" mencegah accidental delete.
Chart di kanan, tabel di kiri Reading pattern kiri → kanan: angka presisi dulu, lalu visual overview. Responsive: stack vertikal di mobile.
