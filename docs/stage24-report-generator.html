1. Ringkasan

Implementasi ReportGeneratorService yang menghasilkan laporan Word (.docx) dari data analisis tracer study menggunakan PHPWord. Laporan mencakup cover page, ringkasan institusi, dan 13 parameter analisis dengan narasi + tabel data. Juga dibangun UI halaman laporan untuk generate, download, dan hapus.

Reports Table

Kolom: Nama File (dengan icon Word), Tracer Study, Ukuran, Dibuat, Aksi (Download + Hapus).

7. ReportController

generate(TracerStudy) → cek isCompleted → service->generate → redirect + success
download(Report)       → Storage::disk('local')->path() → response()->download
destroy(Report)        → unlink file → repository->delete → redirect + success
