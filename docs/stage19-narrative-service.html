1. Ringkasan

NarrativeService menghasilkan teks narasi otomatis dari hasil statistik menggunakan template di config/narratives.php. Service mengganti placeholder dengan data aktual, memformat angka Rupiah, dan menghandle second_text_template untuk runner-up category.

3. Interface

interface NarrativeServiceInterface
{
    public function generate(
        string $parameterKey,
        array $statisticsResult,
        array $meta = [],
    ): string;
}

4. Flow Proses

  1. Ambil template dari config("narratives.{$parameterKey}")
  2. Build replacements dari 3 sumber: meta info, stats result, second_text
  3. Sort keys by length descending (prevent :total matching before :total_sum)
  4. str_replace semua :placeholder dengan nilai

6. Fitur Khusus

6.1 Currency Formatting

Nilai :mean > 10.000 otomatis diformat sebagai Rupiah (titik ribuan):

Rp 4.050.000

6.2 Second Text Template

Placeholder :second_text di-generate dari second_text_template hanya jika second_count > 0:

Sementara Wirausaha sebanyak 1 orang (20%).

6.3 Key Length Sorting

Replacement keys disort descending by length untuk mencegah partial match — contoh: :total_sum harus tergantikan sebelum :total.

7. Contoh Output

frequency (status_setelah_lulus)

Dari 5 responden lulusan Teknik Informatika S1 tahun 2023, mayoritas berstatus Bekerja sebanyak 2 orang (40%). Sementara Wirausaha sebanyak 1 orang (20%).

mean_median (pendapatan_pertama)

Rata-rata pendapatan pertama lulusan setelah bekerja adalah Rp 4.050.000 per bulan, dengan nilai tengah (median) sebesar Rp 3.850.000. Pendapatan terendah tercatat Rp 2.500.000 dan tertinggi Rp 6.000.000.

sum (melamar_pekerjaan)

Total lamaran pekerjaan yang dikirimkan oleh seluruh responden adalah 38 lamaran, dengan rata-rata 9.5 lamaran per orang.

index (kemampuan_diri)

Penilaian kemampuan diri lulusan mencakup 7 kompetensi. Kompetensi Etika memiliki indeks dikuasai tertinggi (4.2), sementara kompetensi Keahlian Bidang menunjukkan gap terbesar antara yang dibutuhkan dan yang dikuasai (-0.6).

8. Bug Fix

Ditemukan dan diperbaiki selama development: :total secara greedy mengganti sebagian dari :total_sum, menghasilkan output "4_sum" bukan "38". Fix: uksort() replacement keys by strlen descending sebelum str_replace().
