1. Ringkasan

Tahap ini mengimplementasikan form upload data tracer study dengan 6 field meta informasi institusi, drag-and-drop file dropzone untuk file Excel (.xlsx), validasi server-side menggunakan FormRequest dengan pesan error Bahasa Indonesia, pengecekan duplikasi data, dan preservasi input setelah validasi gagal.

4.2 Duplicate Check

$existing = $this->tracerStudyRepository->findByProdiAndTahun(
    $request->nama_prodi,
    $request->tahun_lulusan,
    $request->tahun_tracer,
);

if ($existing) {
    return back()->withInput()->with('error',
        'Data tracer untuk prodi, tahun lulusan, dan tahun tracer ini sudah ada.'
    );
}

Pengecekan duplikasi menggunakan 3 kolom: nama_prodi, tahun_lulusan, tahun_tracer — sesuai composite unique index di database.

5. Upload Form UI

File: resources/views/upload.blade.php

5.1 Struktur Form

Card 1 — Informasi Institusi
  • Row 1: Nama Institusi (col-12)
  • Row 2: Program Studi (col-md-8) + Jenjang select (col-md-4)
  • Row 3: Tahun Lulusan (col-md-4) + Tahun Tracer (col-md-4) + Total Lulusan (col-md-4)
Card 2 — File Excel Tracer Study
  • Drag & drop dropzone area
  • Click-to-browse fallback
  • File preview (nama, ukuran, tombol hapus)
  • Accept: .xlsx only, max 10 MB
Action Bar
  • Kembali (link ke dashboard)
  • Upload & Proses (submit button)
