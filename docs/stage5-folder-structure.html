Layer Legend

Setiap file dipetakan ke salah satu layer arsitektur. Warna tag menunjukkan layer mana file tersebut berada.

File Registry: Controllers

FileLayerTanggung JawabDependensi
DashboardController Presentation Menampilkan daftar tracer study terbaru, statistik ringkasan. Method: index() TracerStudyRepositoryInterface
UploadController Presentation Form upload dan proses file. Methods: create(), store() TracerAnalysisService, UploadTracerRequest
AnalysisController Presentation Menampilkan 13 parameter cards + charts. Method: show($id) TracerStudyRepositoryInterface, AnalysisResultRepositoryInterface
ReportController Presentation Daftar laporan, generate Word, download. Methods: index(), generate($id), download($id), destroy($id) ReportGeneratorService, ReportRepositoryInterface
5.4

File Registry: Services

FileLayerTanggung JawabDependensi
TracerAnalysisService Application Orchestrator utama. Menerima file Excel + meta → koordinasi pembacaan, statistik, narasi, chart config → simpan semua hasil ke DB. ExcelReaderService, StatisticsService, NarrativeService, ChartConfigService, TracerStudyRepositoryInterface, AnalysisResultRepositoryInterface
ExcelReaderService Application Baca sheet "data tracer" via PhpSpreadsheet. Return array of associative arrays (1 row = 1 responden, key = f-code). config/tracer.php, PhpSpreadsheet
StatisticsService Application Hitung statistik per parameter berdasarkan tipenya: frequency, mean, median, sum, index. Gunakan Strategy Pattern internal. config/tracer.php
NarrativeService Application Generate paragraf narasi otomatis dari template + hasil statistik. Satu paragraf per parameter. config/narratives.php
ReportGeneratorService Application Buat dokumen .docx lengkap via PHPWord. Isi: cover, daftar isi, ringkasan, 13 bab parameter (tabel + narasi). AnalysisResultRepositoryInterface, TracerStudyRepositoryInterface, PHPWord
ChartConfigService Application Build JSON konfigurasi Chart.js (labels, datasets, colors, options) per parameter. Disimpan di chart_config column. config/tracer.php
5.5

File Registry: Models & Repositories

FileLayerTanggung Jawab
TracerStudy Domain Eloquent model. Relasi: hasMany(AnalysisResult), hasMany(Report). Cast: tahun_tracer → integer, status → enum.
AnalysisResult Domain Eloquent model. Relasi: belongsTo(TracerStudy). Cast: result_data → array, chart_config → array.
Report Domain Eloquent model. Relasi: belongsTo(TracerStudy). Boot: auto-delete file fisik saat model dihapus.
TracerStudyRepositoryInterface Domain Contract: all(), find($id), create(array), updateStatus($id, $status), delete($id)
AnalysisResultRepositoryInterface Domain Contract: findByTracerStudy($id), createMany(array), findByParameter($studyId, $num)
ReportRepositoryInterface Domain Contract: findByTracerStudy($id), create(array), find($id), delete($id)
TracerStudyRepository Infrastructure Implementasi Eloquent dari TracerStudyRepositoryInterface
AnalysisResultRepository Infrastructure Implementasi Eloquent dari AnalysisResultRepositoryInterface
ReportRepository Infrastructure Implementasi Eloquent dari ReportRepositoryInterface

File Registry: Config, Views & Assets

FileLayerTanggung Jawab
config/tracer.php Config Mapping 13 parameter: nama, f-code kolom Excel, tipe statistik, chart type, label kategori. Single source of truth untuk parameter processing.
config/narratives.php Config Template Blade-style string per parameter. Placeholder: :total, :top_category, :top_percentage, :mean, dll.
layouts/app.blade.php Resource Master layout AdminLTE 4. Slot: @yield('content'), @yield('scripts'). Include sidebar + navbar partials.
components/*.blade.php Resource 4 Blade components: parameter-card (tabel+chart per param), chart-container (canvas wrapper), stat-widget (angka highlight), empty-state.
pages/*.blade.php Resource 4 halaman: dashboard, upload, analysis, reports. Masing-masing extend layouts/app.
public/assets/css/custom.css Resource Override AdminLTE styles + custom parameter card styling.
public/assets/js/charts.js Resource Inisialisasi Chart.js instances dari JSON chart_config yang di-pass via Blade.
RepositoryServiceProvider Infrastructure Bind 3 repository interface → Eloquent implementation. Didaftarkan di config/app.php providers.
UploadTracerRequest Presentation Form Request: validasi file (.xlsx, max 10MB), nama_pt, nama_prodi, tahun_tracer, total_lulusan_pt, total_lulusan_prodi.
