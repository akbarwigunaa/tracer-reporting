1. Ringkasan

Implementasi halaman Dashboard utama — landing page aplikasi. Menampilkan 4 summary cards (KPI) dan tabel daftar semua tracer study beserta status, statistik, dan aksi (lihat analisis / hapus). Menggunakan komponen AdminLTE 4 small-box untuk summary cards dan Bootstrap 5 table.

2. File yang Dimodifikasi

resources/views/dashboard.blade.php — dari placeholder menjadi full implementation (147 lines)

3.3 Empty State

Ketika belum ada data: tampil ikon inbox besar, pesan "Belum ada data tracer study", dan tombol "Upload Data Pertama".

    → Summary cards: computed from Collection methods
    → Table: @foreach loop with status badges + action buttons
