9.1

Sequence 1: Upload & Analisis Data

Interaksi paling kompleks. Melibatkan 8 partisipan: Browser, UploadController, TracerAnalysisService, ExcelReaderService, StatisticsService, ChartConfigService, NarrativeService, dan Repository/DB.

Langkah Interaksi Detail
  1. 1Browser → UploadController: store(UploadTracerRequest $request) — HTTP POST /upload dengan file + meta
  2. 2UploadController: UploadTracerRequest otomatis memvalidasi file (.xlsx, ≤10MB) dan 5 field wajib
  3. 3UploadController → TracerAnalysisService: analyze($file, $meta) — delegasi seluruh proses
  4. 4TracerAnalysisService → TracerStudyRepository: create([...meta, status: 'processing']) — simpan record awal
  5. 5TracerAnalysisService → ExcelReaderService: read($filePath) — baca sheet "data tracer" via PhpSpreadsheet → return array of respondents
  6. 6TracerAnalysisService: hitung total_responden, response_rate_pt, response_rate_prodi
  7. 7Loop [1..13]: TracerAnalysisService → StatisticsService: calculate($data, $paramConfig) — hitung sesuai statistic_type
  8. 8TracerAnalysisService → ChartConfigService: build($resultData, $paramConfig) — build JSON konfigurasi Chart.js
  9. 9TracerAnalysisService → NarrativeService: generate($resultData, $paramConfig) — generate paragraf dari template
  10. 10TracerAnalysisService → AnalysisResultRepository: createMany($results) — simpan 13 records analysis_results
  11. 11TracerAnalysisService: Storage::delete($filePath) — hapus file Excel sementara
  12. 12TracerAnalysisService → TracerStudyRepository: updateStatus($id, 'completed')
  13. 13TracerAnalysisService → UploadController: return TracerStudy model (completed)
  14. 14UploadController → Browser: redirect('/analysis/{id}') + flash message sukses
9.2

Sequence 2: Generate Laporan Word

Interaksi 5 partisipan: Browser, ReportController, ReportGeneratorService, Repository, dan Storage.

Langkah Interaksi Detail
  1. 1Browser → ReportController: generate($id) — POST /reports/{id}/generate
  2. 2ReportController → ReportGeneratorService: generate($tracerStudyId)
  3. 3ReportGeneratorService → Repository: ambil TracerStudy + 13 AnalysisResults via find() dan findByTracerStudy()
  4. 4ReportGeneratorService: build dokumen PHPWord — cover page, daftar isi, ringkasan, 13 bab (tabel + narasi)
  5. 5ReportGeneratorService → Storage: Storage::put('reports/xxx.docx', $content)
  6. 6ReportGeneratorService → ReportRepository: create([filename, file_path, file_size])
  7. 7ReportGeneratorService → ReportController: return Report model
  8. 8ReportController → Browser: redirect('/reports') + flash message
9.3

Sequence 3: Lihat Analisis Parameter

Interaksi read-only paling sering diakses. 4 partisipan: Browser, AnalysisController, Repository, dan Blade View.

Langkah Interaksi Detail
  1. 1Browser → AnalysisController: show($id) — GET /analysis/{id}
  2. 2AnalysisController → TracerStudyRepository: find($id) → TracerStudy model (atau 404)
  3. 3AnalysisController → AnalysisResultRepository: findByTracerStudy($id) → Collection of 13 results
  4. 4AnalysisController → Blade View: render analysis.blade.php dengan $study + $results, 13× <x-parameter-card>
  5. 5Blade → AnalysisController: rendered HTML dengan Chart.js JSON inline
  6. 6AnalysisController → Browser: HTTP 200, browser render chart via Chart.js
