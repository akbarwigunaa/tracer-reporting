Test Strategy

Feature Tests

Feature tests use RefreshDatabase with SQLite in-memory. Upload and Report tests exercise the full request lifecycle against a real Excel fixture, verifying end-to-end processing through all 6 services and 13 parameters. This ensures the integration between ExcelReader → Statistics → Narrative → ChartConfig → TracerAnalysis → ReportGenerator works correctly.

Unit Tests

Unit tests isolate individual service logic without HTTP or database dependencies. StatisticsService tests cover all 6 statistic types including edge cases (empty data, even/odd count median). NarrativeService tests verify placeholder replacement ordering (long-before-short to prevent partial matches). ChartConfigService tests verify correct Chart.js config structure for all 3 chart types.

Test Database

Configured in phpunit.xml with DB_CONNECTION=sqlite and DB_DATABASE=:memory: for fast, isolated test execution.

Test Execution

Run the full suite:

php artisan test

Run specific suites:

php artisan test --testsuite=Unit
php artisan test --testsuite=Feature
