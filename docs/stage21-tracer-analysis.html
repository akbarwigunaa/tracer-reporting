1. Ringkasan

TracerAnalysisService adalah orchestrator utama yang mengorkestrasi seluruh pipeline analisis tracer study: menyimpan file Excel → membuat record TracerStudy → membaca data → menghitung statistik → menghasilkan narasi → membangun konfigurasi chart → menyimpan hasil analisis → mengupdate status. Service ini juga diintegrasikan ke UploadController.store().

3. Pipeline Flow

1
Store file — $file->store('tracer-files', 'local') → storage/app/private/tracer-files/
2
Create TracerStudy — status='processing', meta fields, file_path
3
Read Excel — ExcelReaderService → raw data per 13 parameter
4
Count responden — dari jumlah baris parameter pertama; hitung response_rate
5
Update TracerStudy — total_responden + response_rate
6
Loop 13 parameter:
  • StatisticsService.calculate() → result_data
  • NarrativeService.generate() → narrative text
  • ChartConfigService.generate() → chart_config (or null)
  • AnalysisResultRepository.create() → simpan ke DB
7
Update status — 'completed' (sukses) atau 'failed' (RuntimeException)

5. UploadController Integration

try {
    $tracerStudy = $this->tracerAnalysisService->process(
        $request->safe()->except('file'),
        $request->file('file'),
    );
    return redirect()->route('analysis.show', $tracerStudy)
        ->with('success', 'Data tracer berhasil diupload dan dianalisis.');
} catch (RuntimeException $e) {
    return back()->withInput()
        ->with('error', 'Gagal memproses file: ' . $e->getMessage());
}

7. Laravel 13 Fix

Laravel 13 mengubah root local disk dari storage/app/ ke storage/app/private/. File path di-resolve menggunakan Storage::disk('local')->path($filePath) bukan storage_path("app/{$filePath}").
