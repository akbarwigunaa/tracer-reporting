Pendahuluan

1.1 Tujuan Dokumen

Dokumen ini mendefinisikan seluruh kebutuhan perangkat lunak untuk Web Tracer Reporting System. Dokumen menjadi acuan utama dalam perancangan arsitektur, implementasi, dan pengujian sistem.

1.2 Ruang Lingkup Produk

Web Tracer Reporting System adalah aplikasi web yang mengolah data Tracer Study dari file Excel (.xlsx) sesuai template DIKTI menjadi dashboard analitik dan laporan otomatis dalam format Microsoft Word. Sistem tidak menyediakan pengisian kuesioner, registrasi alumni, data cleaning, validasi data, autentikasi pengguna, maupun integrasi API eksternal.

1.3 Definisi & Akronim

Deskripsi Umum

2.1 Perspektif Produk

Sistem merupakan aplikasi standalone yang berjalan di environment lokal atau server perguruan tinggi. Tidak terintegrasi dengan sistem eksternal. Input berupa file Excel, output berupa dashboard web dan dokumen Word.

2.2 Fungsi Utama Produk

  • Membaca dan mengolah data dari file Excel template Tracer Study DIKTI
  • Menghitung statistik (frekuensi, persentase, mean, median, sum) untuk 13 parameter
  • Menampilkan hasil analisis dalam dashboard analitik bergaya BI
  • Menghasilkan grafik otomatis (pie chart, bar chart, grouped bar chart)
  • Menghasilkan narasi interpretasi otomatis per parameter
  • Men-generate laporan formal lengkap dan mengekspornya ke Microsoft Word
  • Menyimpan riwayat laporan untuk diunduh kembali

2.3 Karakteristik Pengguna

Pengguna tunggal tanpa autentikasi. Diasumsikan memahami format template Excel Tracer Study DIKTI dan mengetahui meta informasi institusi (nama PT, nama prodi, total lulusan).

2.4 Batasan Umum

  • Input hanya file .xlsx sesuai template
  • Tidak ada data cleaning atau validasi logika data
  • Tidak ada integrasi API eksternal
  • Tidak ada autentikasi pengguna
  • Export hanya ke format Word (.docx)
  • Setiap upload berdiri sendiri, tidak ada perbandingan antar periode

2.5 Asumsi & Dependensi

  • Server memiliki PHP 8.4+, Composer, MySQL 8+, dan ekstensi PHP yang dibutuhkan Laravel
  • Template Excel memiliki sheet "data tracer" dengan header di baris 3 dan data mulai baris 4
  • Kolom Excel menggunakan f-code DIKTI yang sudah terdefinisi (86 kolom)
  • PhpSpreadsheet dapat membaca file .xlsx tanpa masalah kompatibilitas

Kebutuhan Fungsional

FR-01 Dashboard Ringkasan High
Data hasil analisis tersimpan di database
Query data analisis terbaru, hitung ringkasan statistik utama
Halaman dashboard menampilkan: total responden, tahun tracer, program studi, response rate, grafik ringkasan status alumni, dan statistik utama
FR-02 Upload File Excel High
File .xlsx sesuai template (max 10 MB), plus form meta: nama PT, nama prodi, total lulusan universitas, total lulusan prodi, tahun tracer
Validasi ekstensi file (.xlsx). Simpan file sementara. Simpan meta informasi ke database.
File tersimpan sementara di storage, record tracer_studies dibuat di database, redirect ke proses analisis
FR-03 Input Meta Informasi High
Form fields: nama_pt (string), nama_prodi (string), total_lulusan_pt (integer), total_lulusan_prodi (integer), tahun_tracer (year)
Validasi required & tipe data. Hitung response_rate = total_responden / total_lulusan_prodi × 100%
Meta tersimpan di tabel tracer_studies, response rate dihitung otomatis
FR-04 Pengolahan Data Tracer High
File Excel yang telah diupload, sheet "data tracer", baris 4+
Baca seluruh baris data. Untuk setiap 13 parameter: ambil kolom sesuai mapping, hitung statistik sesuai jenis (COUNTIF/MEAN/MEDIAN/SUM), hitung persentase, generate narasi otomatis. Simpan hasil ke database. Hapus file Excel sementara.
13 set hasil analisis tersimpan di tabel analysis_results, file Excel dihapus
FR-05 Hitung Statistik per Parameter High
Array data dari kolom parameter tertentu
Frekuensi: COUNTIF per kategori, hitung persentase
Mean: rata-rata numerik
Median: nilai tengah
Sum: total penjumlahan
Indeks: rata-rata tertimbang Likert (parameter #13)
Object statistik: {type, categories[], values[], percentages[], mean, median, sum, total_respondents}
FR-06 Generate Grafik Otomatis High
Data statistik per parameter
Render Chart.js sesuai jenis: Pie (#1), Bar (#2–#6, #8), Grouped Bar (#13). Pass data sebagai JSON ke Blade component.
Canvas chart interaktif di browser, dengan legend dan tooltip
FR-07 Generate Tabel per Parameter High
Data statistik per parameter
Format data ke tabel HTML: kolom kategori, jumlah, persentase. Parameter #12: tabel Universitas + Prodi. Parameter #13: tabel 7 kompetensi × (frekuensi per skala + indeks A + indeks B).
Tabel HTML responsif dalam card parameter
FR-08 Generate Narasi Otomatis High
Data statistik dan meta informasi
Untuk setiap parameter, generate paragraf narasi menggunakan template kalimat yang diisi dengan data aktual. Contoh: "Sebanyak {n} responden ({pct}%) berstatus bekerja setelah lulus." Sertakan interpretasi: identifikasi kategori tertinggi/terendah, bandingkan indeks A vs B (#13).
Paragraf narasi bahasa Indonesia formal per parameter
FR-09 Tampilan Card per Parameter High
Hasil analisis 13 parameter
Render setiap parameter dalam card terpisah yang berisi: judul parameter, statistik ringkasan, grafik, tabel detail, dan narasi interpretasi
Halaman analisis dengan 13 card, dikelompokkan per grup (Status Alumni, Bekerja & Wiraswasta, Mencari Kerja, Studi Lanjut, Kompetensi)
FR-10 Generate Laporan Lengkap High
Seluruh hasil analisis + meta informasi
Susun dokumen dengan struktur: Cover (nama PT, prodi, tahun), Daftar Isi, Ringkasan Eksekutif, Hasil Analisis per parameter (narasi + tabel + grafik), Kesimpulan (rangkuman temuan utama), Lampiran
Dokumen laporan siap diekspor
FR-11 Export ke Microsoft Word High
Data laporan yang telah di-generate
Gunakan PHPWord untuk membuat dokumen .docx: set page layout (A4, margin standar), tambahkan cover page, daftar isi, konten per section, tabel dengan styling, gambar grafik (render Chart.js ke image server-side atau gunakan tabel sebagai pengganti). Simpan file ke storage.
File .docx tersimpan di storage/app/reports/, trigger download ke browser
FR-12 Riwayat Laporan Medium
Daftar laporan yang tersimpan di database
Query tabel reports, tampilkan list dengan: nama file, tahun tracer, prodi, tanggal generate, ukuran file. Sediakan tombol download dan hapus.
Halaman daftar riwayat laporan dengan aksi download ulang
FR-13 Hitung Response Rate Medium
Total responden (dari data Excel), total lulusan prodi (input manual)
response_rate = (total_responden / total_lulusan_prodi) × 100. Juga hitung level universitas jika total_lulusan_pt diisi.
Persentase response rate ditampilkan di dashboard dan dimasukkan ke laporan

Aturan Bisnis

IDAturanKeterangan
BR-01 File yang diupload harus berekstensi .xlsx Validasi ekstensi saja, bukan isi file
BR-02 Sheet yang dibaca harus bernama "data tracer" (case-insensitive) Jika sheet tidak ditemukan, tampilkan error
BR-03 Header kolom berada di baris 3, data dimulai baris 4 Baris 1–2 diabaikan
BR-04 Baris data yang seluruh kolom parameternya kosong diabaikan Tidak dihitung sebagai responden
BR-05 Parameter #2 (Lama Kerja): nilai bulan dikategorikan berdasarkan range numerik <6, 6–12, >12 bulan
BR-06 Parameter #7 & #8 menggunakan kolom yang sama (BP/f505) #7 hitung mean+median, #8 kategorikan ke 4 range penghasilan
BR-07 Parameter #13 menghitung indeks per kompetensi: ∑(nilai × frekuensi) / total responden Skala 1–5 (Sangat Kurang–Sangat Baik)
BR-08 Narasi otomatis menggunakan template kalimat dengan placeholder data Bahasa Indonesia formal, tanpa opini
BR-09 File Excel dihapus setelah analisis selesai Tidak ada penyimpanan data mentah
BR-10 Laporan Word tersimpan permanen sampai dihapus manual oleh pengguna Tersimpan di storage/app/reports/
BR-11 Persentase dibulatkan 2 desimal, nilai rupiah tanpa desimal Konsistensi format angka di seluruh output
BR-12 Response rate = (total_responden / total_lulusan) × 100 Dihitung untuk level prodi dan universitas
